# Installing the research GitHub profile

GitHub account: https://github.com/nishantharkut-research

## Profile README

1. Sign into `nishantharkut-research`.
2. Create a **public** repository named exactly `nishantharkut-research` (matching the username).
3. Add the supplied `README.md` to that repository's default branch. GitHub will display it on your profile automatically.
4. Pin `TinyRF-KD`, `Covid-RARS`, and `isac-uav`. You can also pin the two IoT coursework repositories if desired.

## Profile picture

1. On GitHub, open the research account's profile settings.
2. Upload one of the two supplied square PNGs under `assets/` as the account avatar.
3. `avatar-scientist.png` is based on the avatar image you provided. `avatar-flame-atom.png` is an original abstract research mark inspired by the palette and flame motif.
4. The accompanying SVG for the flame/atom mark is included if you want to edit the vector artwork later.

## Suggested profile bio

Applied ML research in edge intelligence, model reliability, and reproducible evaluation | IIITM Gwalior

## Notes

- The GitHub integration currently connects to `nishantharkut` rather than `nishantharkut-research`, so this package has **not** been pushed to the research account.
- The README does not claim any manuscript is published or accepted, and it labels the UAV/ISAC numerical reproduction as pending.
